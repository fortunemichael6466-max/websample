# LUMA Car Care — React + Vite concept

A complete fictional car-wash/detailing website concept with a deliberately different visual direction from NOVA RINSE.

## Direction
- Warm stone, charcoal and terracotta palette
- Outfit + Newsreader typography
- Full-bleed photography and editorial layouts
- No fake ratings, review counts or pricing
- No numbered feature-card grids
- Restrained motion and image reveals
- Full multi-page structure

## Pages
- `/` Home
- `/treatments` Treatments
- `/method` Method
- `/gallery` Gallery
- `/contact` Contact
- `/book` Booking request

## Run
```bash
npm install
npm run dev
```

## Before production
This is a fictional concept brand. Replace image URLs with the real business photography and add real phone, address, opening hours, service inclusions and booking integration.
